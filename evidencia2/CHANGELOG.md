# Registro de cambios

Todos los cambios importantes de este proyecto, por versión. La versión más reciente va arriba.

## [v1.0] — Sprint 2 (11 – 23 nov 2026)

- Implementación completa de la regla R3 para cancelación de reservas.
- Nueva prueba de requisito no funcional (RNF) de rendimiento.
- Pruebas unitarias adicionales para la regla R3.
- Pruebas de aceptación para la regla R3.
- Actualización de la documentación del Sprint 2.
- Actualización de escenarios BDD y tablas FIT.

- Actualización de historias de usuario y backlog del proyecto.

### Corregido
- Corrección de casos que fallaban al procesar el nuevo plan Estudiante.
- Ajustes de validación y compatibilidad con las pruebas de aceptación actualizadas.
